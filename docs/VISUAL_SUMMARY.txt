┌─────────────────────────────────────────────────────────────────────────┐
│ THE PROBLEM                                                             │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ❌ MJPEG stream showed raw, unannotated video                          │
│  ❌ No bounding boxes or detection labels visible                       │
│  ❌ Detections logged but not visible to users                          │
│  ❌ Caused by race condition in feeder loop                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ THE ROOT CAUSE                                                          │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  Camera (30 FPS) ──► Detection (10-15 FPS) ──► Stream (30 FPS)         │
│                                                                         │
│  Timeline:                                                              │
│  T=0ms:   Feeder checks annotated queue → empty                        │
│           └─ Calls update_raw_frame(frame_1)                           │
│                                                                         │
│  T=66ms:  Detection finishes                                           │
│           └─ Calls annotated_queue.put(annotated_frame_1)              │
│                                                                         │
│  T=66ms:  Feeder iteration 2                                           │
│           └─ Calls update_raw_frame(frame_2)  ← OVERWRITES!            │
│                                                                         │
│  Result:  Annotation lost ❌                                            │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ THE SOLUTION                                                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  Implement drain loop in feeder:                                        │
│                                                                         │
│  while True:                                                            │
│    annotated = queue.get(timeout=0.001)  ← Non-blocking, 1ms max      │
│    if annotated is None:                                               │
│      break                                                              │
│    update_annotated_frame(annotated)     ← Process FIRST!              │
│                                                                         │
│  update_raw_frame(raw)                   ← Update AFTER drain           │
│                                                                         │
│  New timeline:                                                          │
│  T=0ms:   Feeder drain loop → empty                                    │
│           └─ update_raw_frame(frame_1)                                 │
│                                                                         │
│  T=66ms:  Detection finishes                                           │
│           └─ annotated_queue.put(annotated_1)                          │
│                                                                         │
│  T=66ms:  Feeder iteration 2                                           │
│           ├─ Drain loop gets annotated_1 ✓                             │
│           ├─ update_annotated_frame(annotated_1) ✓                     │
│           └─ update_raw_frame(frame_2) ✓                               │
│                                                                         │
│  Result:  Annotation preserved ✓                                        │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
